# Contributing

Contributions to this project are welcome.

If you have improvements, bug fixes, documentation updates, or ideas for additional functionality, feel free to open an issue or submit a pull request.

## Before submitting a pull request

Please:

* Explain what the change does.
* Keep changes reasonably focused.
* Test changes on actual hardware when practical.
* Clearly identify any hardware or firmware assumptions.
* Do not include code or other material that you do not have permission to redistribute.

There is no guarantee that every proposed contribution will be accepted or incorporated into the project.

By submitting a contribution, you agree that the contribution may be distributed as part of this project under the project's GNU General Public License, version 2.0 or later.
