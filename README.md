# denon-avr1912-control

## This is a ThingPulse Grande kit with case and battery.  It is programmed to send and receive various commands defined by DENON for the AVR1912 protocol.  It is primarily used as a small portable volume and mute control for Main and Zone-2.  It also list what network radio artist/song/source is.
